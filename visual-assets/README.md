# Rovex visual asset provenance

Imported assets are pinned, license-checked, and copied into the APK by the visual overlay.

- checkmark.json — source: useAnimations/react-useanimations, commit 1ddb15ff428640dce57a377dba31ad357394365d, MIT license. Used for bounded success feedback.
- bookmark.json — source: useAnimations/react-useanimations, commit d701140e0729c4da332413ae665363de8505b4a2, MIT license. Used for bookmark feedback.
- loading.json — source: useAnimations/react-useanimations, commit cbf87e18503f65f7e0197de3e043c31fc3c2a41b, MIT license. Rovex stores a lightweight adapted variant for bounded loading feedback; it is not represented as an unmodified upstream copy.
